# Обновления ContractPrintApp

## GitHub без авторизации

Начиная с 1.12.0 источник по умолчанию — публичные релизы
`Admutium/ContractPrintApp`. Вход в GitHub и токены не нужны.
При запуске программа проверяет наличие версии; автоматические запросы
ограничены интервалом 6 часов. Вручную проверить можно в любой момент:
«Настройки → Проверить обновления». При появлении версии предлагается
скачать её, затем подтвердить закрытие и установку. Есть индикатор процентов.

Если сеть прервалась, повторите проверку: сохранённая часть загрузки
используется для докачки. При неподдерживаемом Range загрузка начинается
заново; повреждённые данные не устанавливаются. Пакет проверяется по SHA-256,
версии и идентификатору продукта. HTTPS и проверка сертификатов обязательны.
Цифровой подписи пакетов пока нет. Справочник и документы на GitHub не отправляются.

Для выбора источника: «Настройки → Обновления из GitHub (без входа)».
«Отключить проверку обновлений» выключает автоматические проверки;
ручная проверка продолжает работать.

## Первая установка 1.12.0

При ошибке ZIP в старой версии выполните одну ручную замену.
Скачайте обычный Windows ZIP, закройте программу на всех ПК и распакуйте
программу в отдельную папку ContractPrintApp. Сохраните существующую папку
`user-data` и перенесите её рядом с новым EXE. Запускайте ContractPrintApp.exe.
Смешивать файлы разных приложений в одной установке не нужно.
После этой установки дальнейшие выпуски загружаются непосредственно с GitHub.

## Сетевая папка как дополнительный источник

В меню «Настройки → Папка обновлений» выберите папку с
`update-ContractPrintApp.json` и соответствующим ZIP обновления.
Запись в папку разрешите ответственному за выпуск версий.
Готовый комплект `ContractPrintApp-1.12.0-update-kit.zip` распакуйте в такую
папку; внутренний ZIP распаковывать не нужно. Команда подготовки пакета:

```bat
python updater.py dist\ContractPrintApp "\\server\software\UpdatesApp" 1.12.0
```

## Установка и общая папка программы

Перед подтверждением сохраните нужный PDF — карточка между запусками
не сохраняется. Если EXE общий для нескольких ПК, закройте его на остальных
ПК. Помощник ожидает освобождения установки, заменяет программу, выполняет
самопроверку и запускает приложение. При ошибке запуска возвращается
предыдущая версия. Папка user-data сохраняется.

Рядом с установкой используется `.ContractPrintApp.update.lock`.
Выполняющему обновление нужны права создания и замены папок рядом с программой.
Закреплённые ярлыки Windows могут показывать старый значок: переприкрепите EXE.
