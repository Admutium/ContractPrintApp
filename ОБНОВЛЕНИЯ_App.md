# Обновления ContractPrintApp

В меню «Настройки → Папка обновлений» выберите сетевую папку с файлом
`update-ContractPrintApp.json`. Проверка выполняется при запуске и вручную.
Запись в сетевую папку разрешите только ответственному за выпуск обновлений.
SHA-256 проверяет целостность пакета; цифровой подписи пакетов нет.

На ПК с Python после успешной сборки выполните:

```bat
python updater.py dist\ContractPrintApp "\\server\software\UpdatesApp" 1.11.0
```

Для следующего выпуска укажите его новый номер; номер должен совпадать с
`BUILD_INFO.txt` готовой сборки. Команда создаёт ZIP готовой программы и
файл `update-ContractPrintApp.json` с идентификатором продукта.
Чужие идентификаторы продукта и несовпадающие метаданные сборки отклоняются.

Пользователь сохраняет PDF и подтверждает закрытие программы. Помощник ждёт
освобождения установки, заменяет файлы, проверяет запуск и сохраняет
резервную копию. Папка `user-data` переносится в новую установку автоматически.
При ошибке самопроверки восстанавливается прежняя установка.

Если EXE общий для нескольких ПК, перед обновлением закройте его на всех ПК.
Рядом с установкой создаётся `.ContractPrintApp.update.lock`; всем пользователям
нужно чтение этого файла, обновляющему — запись и право замены папки установки.
Программа не обращается к GitHub за обновлениями и не передаёт справочник.
