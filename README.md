# ContractPrintApp 1.14.1

Приложение для создания карточки контракта, формирования PDF и печати.

Карточка печатается на обороте последнего листа комплекта. Через секунду
после открытия HTML программа автоматически получает данные ЕИС и переносит
распознанные поля без подтверждения. Ручные изменения сохраняются.

Вкладка «Платёжное поручение» создаёт внутренний документ для бухгалтерии.
В документ входят полное название плательщика, данные ЛПУ, реквизиты из пункта
5.5 и размер обеспечения с процентом. Предпросмотр создаётся при открытии
вкладки. Документ можно сохранить и напечатать на одном листе A4.

[Скачать готовую программу для Windows](https://github.com/Admutium/ContractPrintApp/releases/download/v1.14.1/ContractPrintApp-1.14.1-windows.zip)
— распакуйте архив в отдельную папку и запустите `ContractPrintApp.exe`.
Python для запуска готовой программы не требуется.

Обновления проверяются автоматически через публичный GitHub, без авторизации.
Проверка и скачивание используют обычные ссылки github.com, без GitHub API.
При наличии новой версии программа предлагает скачать её, затем подтвердить
установку. Прерванную загрузку можно продолжить повторной проверкой.
Команда «Настройки → Проверить обновления» запускает проверку вручную.

[Комплект для проверки автообновления](https://github.com/Admutium/ContractPrintApp/releases/download/v1.14.1/ContractPrintApp-1.14.1-update-kit.zip)
— распакуйте в отдельную папку обновлений, затем выберите её в настройках
установленной программы. Подробности: `ОБНОВЛЕНИЯ_App.md`.

[Значок ICO](https://github.com/Admutium/ContractPrintApp/releases/download/v1.14.1/ContractPrintApp.ico).

При первом запуске справочник организаций пуст. Добавьте свои организации
в «Настройки → Справочник организаций»: код, ИНН и название. После этого
поставщик определяется по ИНН загруженного документа. Для ручного выбора
используется выпадающий список.

Настройки хранятся в `user-data/settings.json` рядом с программой. Папка
программы должна быть доступна на запись. Документы загружаются пользователем;
карточка не сохраняется между запусками. PDF сохраняются в выбранную папку.

## Windows

Установите Python 3.11–3.14 x64 с Tcl/Tk для текущего пользователя.
Запустите `BUILD_WINDOWS_App.cmd`. Готовая программа:
`dist\ContractPrintApp\ContractPrintApp.exe`.
На другие ПК переносится вся папка `ContractPrintApp`, включая `_internal`.
Python на этих ПК не требуется. Пользовательскую папку `user-data` сохраняйте.

Краткие инструкции: `ИНСТРУКЦИЯ_App.txt`, `ОБНОВЛЕНИЯ_App.md`.
Сведения о проверках: `ПРОВЕРКА_App.txt`.
