# ContractPrintApp 1.11.0

Приложение для создания карточки контракта, формирования PDF и печати.

[Скачать готовую программу для Windows](https://github.com/Admutium/ContractPrintApp/releases/download/v1.11.0/ContractPrintApp-1.11.0-windows.zip)
— распакуйте архив в отдельную папку и запустите `ContractPrintApp.exe`.
Python для запуска готовой программы не требуется.

При первом запуске справочник организаций пуст. Добавьте свои организации
в «Настройки → Справочник организаций»: код, ИНН и название. После этого
поставщик определяется по ИНН загруженного документа. Для ручного выбора
используется выпадающий список.

Настройки хранятся в `user-data/settings.json` рядом с программой. Папка
программы должна быть доступна на запись. Документы загружаются пользователем;
карточка не сохраняется между запусками. PDF сохраняются в выбранную папку.

## Windows

Установите Python 3.11–3.14 x64 с Tcl/Tk для текущего пользователя.
Запустите `BUILD_WINDOWS_App.cmd`. Готовая программа:
`dist\ContractPrintApp\ContractPrintApp.exe`.
На другие ПК переносится вся папка `ContractPrintApp`, включая `_internal`.
Python на этих ПК не требуется. Пользовательскую папку `user-data` сохраняйте.

Краткие инструкции: `ИНСТРУКЦИЯ_App.txt`, `ОБНОВЛЕНИЯ_App.md`.
Сведения о проверках: `ПРОВЕРКА_App.txt`.
