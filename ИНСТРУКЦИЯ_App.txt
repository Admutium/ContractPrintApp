ContractPrintApp 1.14.0

1. Распакуйте программу в отдельную папку ContractPrintApp с правом записи.
2. Запустите ContractPrintApp.exe. Для сборки из исходников используйте
   BUILD_WINDOWS_App.cmd на Windows с Python 3.11–3.14 x64 и Tcl/Tk.
3. В «Настройки → Справочник организаций» добавьте код, ИНН и название,
   нажмите «Применить строку», затем «Сохранить справочник».
4. Загрузите HTML печатной формы электронного контракта. Организация
   определяется по ИНН только при наличии соответствующей записи в справочнике.
5. Через секунду после открытия HTML начинается загрузка ЕИС без подтверждения.
   Распознанные данные переносятся автоматически, ваши ручные правки сохраняются.
   При недоступности ЕИС можно продолжать работу и нажать «Получить из ЕИС» позже.
   Проверьте данные, при необходимости загрузите сроки из Word.
   В окне Word найденную формулировку можно исправить перед переносом.
   Если срок не найден, введите его в ручное поле и отметьте перенос.
   Периодичность услуг сохраняется целиком; отчётные периоды нужно сверять отдельно.
6. Сформируйте PDF и сохраните его в выбранную папку либо отправьте на печать.
   Карточка находится на обороте последнего листа. Для ручной двусторонней
   печати сначала напечатайте лицевые, затем оборот только последнего листа.

Настройки: user-data/settings.json рядом с EXE. Эта папка содержит ваши
локальные данные. Сохраняйте её при переносе программы и не включайте в
распространяемые сборки. Автообновление сохраняет её на месте.
При запуске из общей папки данные общие; редактируйте справочник с одного ПК.
Для отдельных справочников установите программу отдельно на каждом ПК.

Закройте PDF и панель предпросмотра Проводника перед заменой сохранённого PDF.
Карточка между запусками не сохраняется: перед закрытием сохраните нужный PDF.

ПЛАТЁЖНОЕ ПОРУЧЕНИЕ — ОБЕСПЕЧЕНИЕ ИСПОЛНЕНИЯ
Откройте вкладку «Платёжное поручение» после загрузки HTML контракта.
До открытия вкладки шаблон и PDF не создаются. Вкладка расположена рядом
с «Организации». Справа появится отдельный предпросмотр одной страницы A4.
Плательщик — наша организация; используется её полное наименование.
Реквизиты для обеспечения заявки и гарантийных обязательств не переносятся.
Если меняете фирму, проверьте и заполните её банковские реквизиты.

Выберите размер: «Из извещения», «% от НМЦК», «% от цены контракта»
или «Своя сумма». Неоднозначное основание не выбирается автоматически.
Проверьте процент, сумму, получателя, номер, дату и назначение платежа.
Лицевой счёт добавляется в назначение. Повышение по статье 37 автоматически
не применяется; при необходимости укажите требуемые процент или сумму.
Длинный текст в поле можно прокручивать стрелками; в PDF он переносится целиком.
Кнопки «Сохранить PDF» и «Печать» работают с открытой вкладкой.
С незаполненными обязательными полями можно сформировать только черновик.
Печать — одна страница A4, односторонняя. Реквизиты платежа остаются только
в текущем сеансе; перед закрытием сохраните PDF. Платежи в банк не отправляются.
