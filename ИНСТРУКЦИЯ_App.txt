ContractPrintApp 1.11.1

1. Распакуйте программу в отдельную папку ContractPrintApp с правом записи.
2. Запустите ContractPrintApp.exe. Для сборки из исходников используйте
   BUILD_WINDOWS_App.cmd на Windows с Python 3.11–3.14 x64 и Tcl/Tk.
3. В «Настройки → Справочник организаций» добавьте код, ИНН и название,
   нажмите «Применить строку», затем «Сохранить справочник».
4. Загрузите HTML печатной формы электронного контракта. Организация
   определяется по ИНН только при наличии соответствующей записи в справочнике.
5. Проверьте данные, при необходимости загрузите извещение ЕИС и сроки из Word.
6. Сформируйте PDF и сохраните его в выбранную папку либо отправьте на печать.

Настройки: user-data/settings.json рядом с EXE. Эта папка содержит ваши
локальные данные. Сохраняйте её при переносе программы и не включайте в
распространяемые сборки. Автообновление сохраняет её на месте.
При запуске из общей папки данные общие; редактируйте справочник с одного ПК.
Для отдельных справочников установите программу отдельно на каждом ПК.

Закройте PDF и панель предпросмотра Проводника перед заменой сохранённого PDF.
Карточка между запусками не сохраняется: перед закрытием сохраните нужный PDF.
